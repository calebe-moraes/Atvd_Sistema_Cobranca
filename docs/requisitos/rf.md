# Requisitos Funcionais (RF)

| ID | Nome | Descrição |
|:---|:---|:---|
| RF01 | Importação de Títulos | O sistema deve permitir a entrada de títulos via arquivo .CSV ou integração API. |
| RF02 | Notificação Multicanal | O sistema deve disparar notificações automáticas via WhatsApp e E-mail simultaneamente à entrada no Call Center. |
| RF03 | Portal de Autoatendimento | O devedor deve conseguir visualizar sua dívida e gerar boletos sem auxílio humano. |
| RF04 | Gestão de Acordos | O sistema deve permitir o parcelamento da dívida com cálculo automático de juros compostos. |
| RF05 | Automação de Protesto | Se esgotadas as tentativas (1ª, 2ª carta e Cobrador), o sistema deve enviar o título para o cartório digital. |
| RF06 | Repasse Financeiro | Após a compensação do pagamento, o sistema deve agendar a transferência para a conta da contratante. |
